# Frontend Mentor Projects

Colección de proyectos de Frontend Mentor. La página principal muestra las categorías y enlaces a cada reto.

## Tecnologías

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4

## Desarrollo

```bash
npm run dev
```

Luego abre http://localhost:3000.

La página de inicio está en `src/app/page.tsx`.

## UI

- Diseño responsive con grid (1, 2 y 3 columnas según ancho).
- Modo oscuro con clases `dark:` activadas por Tailwind.
